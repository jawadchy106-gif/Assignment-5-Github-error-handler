Q1. What is the difference between var, let, and const?
Ans: var, let, and const are used to declare variables in JavaScript. let allows the value to change later, while const is used for values that should not be reassigned.

Q2. What is the spread operator (...)?
Ans: The spread operator (...) is used to expand or unpack elements from an array or properties from an object. It makes it easier to copy arrays, combine arrays, or pass multiple values to a function. It improves readability and reduces code complexity.

Q3. What is the difference between map(), filter(), and forEach()?
Ans: All three are array methods used to work with elements inside an array. map() creates a new array by transforming each element of the original array. filter() also returns a new array, but only with elements that match a specific condition. forEach() simply runs a function for each element but does not return a new array.

Q4. What is an arrow function?
Ans: An arrow function is a shorter and cleaner way to write functions in JavaScript. Arrow functions are commonly used for simple operations and callbacks.

Q5. What are template literals?
Ans: Template literals are a way to create strings in JavaScript using ` instead of quotes. They allow you to easily include variables or expressions inside a string using ${}.
